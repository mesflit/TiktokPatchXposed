## 4.4.5 (fork)

**New: Background play** — Settings → TiktokPatchXposed → Playback → *Background play*. Off by default.

- Feed videos keep playing with the screen off, or with TikTok in the background.
- If auto-scroll is on, it keeps moving to the next video in the background too
  (search, Following, chats, profiles; on For You when TikTok's own auto-scroll is on, or "Auto-scroll everywhere").
- A phone call or another app taking the audio stops it; opening TikTok again returns to normal.

**Yeni: Arka planda oynatma** — Ayarlar → TiktokPatchXposed → Oynatma → *Arka planda oynatma*. Varsayılan olarak kapalı.

- Ekran kapalıyken veya TikTok arka plandayken videolar oynamaya devam eder.
- Otomatik kaydırma açıksa arka planda da sonraki videoya geçer.
- Telefon araması veya başka bir uygulamanın sesi oynatmayı durdurur.

This build is signed with the fork's own key: uninstall the original module once before installing it.
